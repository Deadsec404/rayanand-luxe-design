## How to Add or Replace Your Own Images

1. To replace any image on the website, simply save your new image with the matching filename above inside `public/assets/images/` (or `assets/images/`).
2. Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`, `.svg`.
3. The website immediately references `/assets/images/<filename>` so your new photos will be loaded instantly!
